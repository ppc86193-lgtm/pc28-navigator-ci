M. 性能目标分段验收（强约束；数据真供给为前提）

本方案不造数。性能验收基于真账：score_ledger_prod_v（tag∈{NULL, ‘prod’}）。
验收采用“逐段达标”与“Wilson置信下界”以防偶然波动。

M1. 24h覆盖率趋势

bq --location=${BQLOC} query --use_legacy_sql=false --format=csv "
WITH D AS (SELECT DATE(created_at,'${TZ}') d, market,
           COUNTIF(outcome IN ('win','lose')) AS settled,
           COUNT(*) AS n_all
           FROM \`${PROJECT}.${DS_LAB}.score_ledger_prod_v\`
           WHERE TIMESTAMP_DIFF(CURRENT_TIMESTAMP('${TZ}'), created_at, HOUR) <= 24
           GROUP BY d, market)
SELECT market, SUM(settled) AS settled_24h, SAFE_DIVIDE(SUM(n_all),
       (SELECT COUNT(*) FROM \`${PROJECT}.${DS_LAB}.draws_today_v2\`)) AS cov_24h
FROM D GROUP BY market"

	•	期望：cov_24h 向0.50收敛，至少≥0.35 作为“一阶达标”。

M2. 24h准确率与Wilson下界

bq --location=${BQLOC} query --use_legacy_sql=false --format=csv "
WITH S AS (
  SELECT market, outcome
  FROM \`${PROJECT}.${DS_LAB}.score_ledger_prod_v\`
  WHERE TIMESTAMP_DIFF(CURRENT_TIMESTAMP('${TZ}'), created_at, HOUR) <= 24),
C AS (SELECT market,
             COUNTIF(outcome IN ('win','lose')) AS settled,
             SAFE_DIVIDE(COUNTIF(outcome='win'), NULLIF(COUNTIF(outcome IN ('win','lose')),0)) AS acc
      FROM S GROUP BY market),
W AS (SELECT market, acc, settled,
             SAFE_DIVIDE(acc + (POW(1.96,2)/(2*settled)) - 1.96*SQRT((acc*(1-acc)+POW(1.96,2)/(4*settled))/settled),
                         1 + POW(1.96,2)/settled) AS wl
      FROM C)
SELECT market, settled, acc, wl FROM W"

	•	期望：当 settled ≥ 100 时，acc ≥ 0.80 且 wl ≥ 0.60。
	•	未达：允许PI+自切继续工作；48小时内应上升至目标区间。否则需审计上游信号质量（非本方案可控）。

M. 性能目标分段验收（强约束；数据真供给为前提）

本方案不造数。性能验收基于真账：score_ledger_prod_v（tag∈{NULL, ‘prod’}）。
验收采用“逐段达标”与“Wilson置信下界”以防偶然波动。

M1. 24h覆盖率趋势

bq --location=${BQLOC} query --use_legacy_sql=false --format=csv "
WITH D AS (SELECT DATE(created_at,'${TZ}') d, market,
           COUNTIF(outcome IN ('win','lose')) AS settled,
           COUNT(*) AS n_all
           FROM \`${PROJECT}.${DS_LAB}.score_ledger_prod_v\`
           WHERE TIMESTAMP_DIFF(CURRENT_TIMESTAMP('${TZ}'), created_at, HOUR) <= 24
           GROUP BY d, market)
SELECT market, SUM(settled) AS settled_24h, SAFE_DIVIDE(SUM(n_all),
       (SELECT COUNT(*) FROM \`${PROJECT}.${DS_LAB}.draws_today_v2\`)) AS cov_24h
FROM D GROUP BY market"

	•	期望：cov_24h 向0.50收敛，至少≥0.35 作为“一阶达标”。

M2. 24h准确率与Wilson下界

bq --location=${BQLOC} query --use_legacy_sql=false --format=csv "
WITH S AS (
  SELECT market, outcome
  FROM \`${PROJECT}.${DS_LAB}.score_ledger_prod_v\`
  WHERE TIMESTAMP_DIFF(CURRENT_TIMESTAMP('${TZ}'), created_at, HOUR) <= 24),
C AS (SELECT market,
             COUNTIF(outcome IN ('win','lose')) AS settled,
             SAFE_DIVIDE(COUNTIF(outcome='win'), NULLIF(COUNTIF(outcome IN ('win','lose')),0)) AS acc
      FROM S GROUP BY market),
W AS (SELECT market, acc, settled,
             SAFE_DIVIDE(acc + (POW(1.96,2)/(2*settled)) - 1.96*SQRT((acc*(1-acc)+POW(1.96,2)/(4*settled))/settled),
                         1 + POW(1.96,2)/settled) AS wl
      FROM C)
SELECT market, settled, acc, wl FROM W"

	•	期望：当 settled ≥ 100 时，acc ≥ 0.80 且 wl ≥ 0.60。
	•	未达：允许PI+自切继续工作；48小时内应上升至目标区间。否则需审计上游信号质量（非本方案可控）。
